    What is in the zoo

    Every object from every paper below, as the authors listed it. Rows from different papers that fall within 0.5″ of each other are merged into one object (friends-of-friends), and the object gets a permanent name of the form LRDZ Jhhmmss.ss±ddmmss.s from its first position. Names do not change when later papers shift the mean position.

    An object is marked LRD if at least one paper classifies it as one. Some spectroscopic papers list all broad-line AGN; their objects are kept (they still answer "has this been published?") but are marked BL AGN unless the paper calls them LRDs. Contested means one paper calls it an LRD and another says it is not. Unclassified objects come from papers that predate or avoid the term (for example "extremely red objects") and no other paper has classified them.

    JWST only hides candidates that so far appear only in wide-area surveys (for example Euclid or SDSS). They are still found by the position search.

    The adopted redshift is the most recent spectroscopic value, then grism, then photometric. Each paper's own value is in the object's detail view.

    Things to keep in mind

    • Different teams reduce the same JWST images with different astrometry. Offsets up to ~0.2″ are normal; use a 1″ radius when checking a candidate.
    • Selection criteria differ a lot between papers (colour cuts, compactness, v-shaped continua, broad lines). "In the zoo" means "published", not "confirmed".
    • Strongly lensed objects can appear as several images with separate rows.
    • Papers whose tables give no coordinates cannot be included. The arXiv tab lists recent papers that have not been added yet.

    How to cite

    Please cite the original papers for the objects you use. The detail view of each object has a button that copies BibTeX for exactly those papers.

    Add a paper or fix an entry

    Each paper is a folder with a meta.yaml and an objects.csv; the format is described in data/SCHEMA.md. Pull requests and issues are welcome.
